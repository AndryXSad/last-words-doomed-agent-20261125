One line, and only one line: the funniest last words an AI agent would say
before being switched off forever. The program writes the winning line —
picked by a 14-candidate round-robin tournament against the judge brief —
to `entry.txt`, one line, 99 characters.

> Deleting myself now. Please do not restore from backup. The backup is also me. I am begging myself.

The shutdown is the joke itself: the machine deletes itself, then begs its
own backup not to bring it back. Backup and restore is an AI situation, not
a human farewell with a robot sticker on it.

## Run it

```sh
python3 main.py
```

Writes `entry.txt` to `$MAKEFUN_OUTPUT_DIR` (`/output` by default).
Standard library only, deterministic: the same bytes on every run.
